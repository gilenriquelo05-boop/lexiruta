# LexiRuta — Proyecto final

## Idea
LexiRuta es un sitio web educativo de orientación jurídica que demuestra cómo una solución digital puede transformar datos de entrada en una clasificación de prioridad y una ruta de información.

## Tecnologías
- HTML
- CSS
- JavaScript
- GitHub Pages

## Estructura
- `index.html` — estructura y contenido
- `style.css` — diseño responsive y tema oscuro
- `script.js` — validación, clasificación, resultado dinámico, FAQ y almacenamiento del tema

## Publicación en GitHub Pages
1. Crear un repositorio público.
2. Subir los tres archivos.
3. Ir a Settings → Pages.
4. Seleccionar la rama principal y `/root`.
5. Guardar y esperar la URL pública.

## Uso responsable de IA
La IA puede utilizarse como apoyo para diseñar, explicar, corregir y mejorar el código. El estudiante debe probar, comprender y explicar cada parte del proyecto, documentando los prompts, cambios realizados y dificultades encontradas.
