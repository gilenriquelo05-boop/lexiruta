01 · PROBLEMA

La información jurídica existe,
pero no siempre es fácil de entender.

Una persona puede identificar que tiene un problema y, aun así, no saber qué información reunir, qué tan urgente puede ser o cuál debería ser su siguiente paso.

01

Desorientación

La persona no sabe cómo ordenar la situación ni qué datos son relevantes.

02

Urgencia invisible

Una notificación, plazo o riesgo puede pasar desapercibido si no se identifica a tiempo.

03

Lenguaje complejo

Los conceptos jurídicos pueden resultar técnicos para quien no tiene formación en Derecho.

02 · SOLUCIÓN

Una ruta digital en tres pasos.

LexiRuta no sustituye a un profesional. Su objetivo académico es demostrar cómo una interfaz puede transformar datos de entrada en un resultado útil y explicable.

1

Captura

El usuario selecciona el área y responde preguntas sencillas.

2

Clasificación

JavaScript asigna una puntuación de prioridad según las respuestas.

3

Ruta

La página genera una recomendación educativa y un checklist de información.

04 · INNOVACIÓN

¿Qué demuestra técnicamente el proyecto?

⚡

Interactividad

Eventos, validación de formularios, condiciones y resultados dinámicos con JavaScript.

◈

Diseño responsive

La interfaz se adapta a celular, tablet y computadora sin depender de frameworks.

◉

Arquitectura clara

HTML, CSS y JavaScript están separados en archivos con nombres limpios para GitHub Pages.

✓

Uso responsable de IA

El código puede documentarse explicando qué se generó, qué se corrigió y cómo se comprendió.

05 · USUARIOS

¿Para quién está pensada LexiRuta?

LexiRuta está diseñada como una herramienta educativa para ayudar a comprender una situación jurídica, ordenar información relevante y reconocer posibles factores de urgencia.

◉

Personas con una situación jurídica

Ayuda a organizar los datos básicos de una situación y reconocer qué información puede ser importante antes de buscar orientación profesional.

◇

Estudiantes de Derecho

Permite observar de manera práctica cómo los datos de entrada pueden convertirse en una clasificación y una ruta de orientación.

→

Usuarios que buscan una orientación inicial

Ofrece una primera referencia educativa sobre la posible prioridad de una situación, sin sustituir la asesoría de un profesional.
